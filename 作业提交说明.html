一、项目概述

    本平台（Global Wind & Lithium Talent Radar，简称 WLR）是一个面向全球风能（Wind Energy）与锂电（Lithium Battery）领域的人才搜索与评估系统。平台基于 Next.js 14（App Router）构建，整合了 102+ 全球真实研究者数据，通过 AI 智能推荐算法，为新能源企业、高校研究所、猎头机构提供精准的人才发现、对比、评估一体化服务。

核心功能包括：

  1. 实时人才搜索：支持关键词、行业、国家三维筛选；
  2. AI 智能推荐：基于匹配评分算法自动排名；
  3. 人才对比功能：支持最多 4 人并排对比；
  4. 数据来源标注：真实数据（arXiv / Crossref）与本地模拟数据双模式；
  5. 角色权限体系：企业 HR / 候选人 / 管理员三权分立。

三、搜索人才完整流程

3.1 进入搜索页面

登录成功后，有两种方式进入人才搜索页面：

  1. 方式一：点击左侧侧边栏的「人才搜索」按钮（🌐 Globe 图标），直接跳转至 /searches 页面；
  2. 方式二：点击首页（Hero Section）的「开始搜索人才」CTA 按钮，跳转至 /searches。

3.2 输入搜索条件

搜索页面顶部提供以下筛选条件：

  1. 关键词输入框：输入技术方向，如「wind turbine」「solid state battery」「BMS」「复合材料」等；
  2. 行业筛选：选择「风能」「锂电」或「全部」；
  3. 国家/地区：选择目标国家（中国、德国、丹麦、美国等 12 个选项）；
  4. 经验年数：设置最低经验要求（1-20 年滑块）。

3.3 执行搜索

设置完筛选条件后，点击「搜索」按钮（🔍 图标）。系统将：

  1. 优先调用真实数据源（arXiv API、Crossref API）抓取全球最新研究者信息；
  2. 若真实数据源不可用，自动回退至本地 102 条模拟人才库；
  3. 搜索结果按「匹配评分」从高到低排列，评分范围为 0-100 分。

3.4 查看搜索结果

搜索结果以卡片网格形式展示，每张卡片包含：

  1. 人才姓名与职称；
  2. 所属机构（大学 / 企业）；
  3. 国家 / 城市；
  4. 匹配评分（绿色进度条可视化）；
  5. 核心亮点标签（最多 3 个）；
  6. 风险标记（如有）；
  7. 数据来源标签（🟢 真实数据 / 🟡 本地模拟）。

3.5 加入对比

若需要对多位候选人进行横向对比，可以：

  1. 在任意候选人卡片上点击「加入对比」按钮；
  2. 页面底部会出现对比悬浮栏，显示已选人数（最多 4 人）；
  3. 点击悬浮栏中的「查看对比」按钮，跳转至 /compare 页面；
  4. 在对比页面中，可以并排查看各位候选人的详细信息，包括评分、亮点、风险、论文数、专利数等维度。

四、技术架构说明

4.1 技术栈

层级 技术选型
前端框架Next.js 14（App Router）+ React 18 + TypeScript
UI 组件Tailwind CSS + shadcn/ui + Lucide Icons
数据可视化Recharts（AreaChart、BarChart、RadarChart）
AI 层Mock Provider（可切换真实 AI）+ 真实数据抓取层
数据源arXiv API（预印本）、Crossref API（学术论文）、本地人才库（102 条）
认证系统JWT + Mock Auth（支持 admin / boss 双账号）

4.2 项目目录结构

app/            — Next.js App Router 页面路由（54 个页面）
components/    — React 组件库（tech/ 科技组件、shared/ 公共组件）
lib/ai/        — AI 抽象层 + 人才数据库 + 真实数据抓取器
lib/i18n/      — 中英文国际化翻译系统
lib/services/   — 后端服务层（订阅、用量、通知等）
prisma/        — 数据库 Schema 定义（User、Candidate、Job 等）
public/         — 静态资源（图片、图标、字体）

4.3 本地运行方式（如公网隧道失效）

  1. 进入项目目录：cd global-talent-radar；
  2. 安装依赖：npm install；
  3. 启动开发服务器：npm run dev；
  4. 浏览器访问：http://localhost:3000。
